## Three Git Commands I Learned
1. git init — Initializes a new Git repository.
2. git add . — Stages changes for the next commit.
3. git commit -m "message" — Saves staged changes with a commit message.

## Purpose of GitHub
.GitHub hosts Git repositories online and supports collaboration, code review, and project sharing.
.GitHub is a platform used to host repositories, share code, and collaborate with other developers.

## One Benefit of Branches
.Branches allow developers to work on new features separately without directly affecting the main branch
